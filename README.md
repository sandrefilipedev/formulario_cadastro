📋 Sistema de Ficha Cadastral em Python
📖 Visão Geral

Este projeto consiste em uma aplicação de linha de comando desenvolvida em Python para gerenciamento de uma ficha cadastral dinâmica.
A solução permite ao usuário cadastrar informações personalizadas, consultar dados específicos e visualizar todos os registros armazenados durante a execução do programa.
O projeto foi desenvolvido com foco no estudo e aplicação de conceitos fundamentais da linguagem Python, especialmente estruturas de dados, controle de fluxo e interação com o usuário através do terminal.

🎯 Objetivo
Demonstrar a utilização prática de dicionários em Python para armazenamento e recuperação de informações em tempo de execução, simulando o funcionamento básico de uma ficha cadastral digital.
Além do aspecto funcional, o projeto busca reforçar conceitos essenciais da programação, como organização lógica, validações simples e manipulação de dados estruturados.
💡 Problema Resolvido
Em aplicações reais, frequentemente é necessário armazenar informações de forma organizada e acessá-las posteriormente de maneira rápida e eficiente.
Este projeto apresenta uma solução simples baseada em dicionários (dict), permitindo que novos campos sejam adicionados dinamicamente sem a necessidade de alterar a estrutura do código.
A abordagem utilizada demonstra como construir sistemas flexíveis capazes de trabalhar com diferentes tipos de informações utilizando pares chave → valor.

🚀 Funcionalidades
Cadastro de informações personalizadas.
Consulta de campos específicos.
Visualização completa da ficha cadastral.
Validação da existência de campos.
Menu interativo para navegação.
Encerramento controlado da aplicação.
🛠️ Tecnologias Utilizadas
Python 3
Estruturas de Dados (Dictionary)
Estruturas Condicionais (if, elif, else)
Estruturas de Repetição (while)
Entrada e Saída de Dados (input() e print())
